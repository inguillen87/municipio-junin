Guía rápida

Antes de compartir

  1. Confirmá el corte. La publicación refleja un respaldo histórico, no el estado de hoy.
  2. Elegí el formato correcto. Web para analizar; vista imprimible para circular una síntesis.
  3. Conservá la fuente visible. El informe incluye el origen, la fecha y los límites de lectura.

Las planillas con datos personales no están habilitadas. Para exportarlas se necesita autorización expresa y el acceso debe quedar registrado.
