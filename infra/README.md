# Infraestructura on-premise

Los archivos ejecutables heredados de Docker Compose, Nginx y variables fueron
retirados porque no representaban la arquitectura actual y podían publicar el
checkout o iniciar servicios no gobernados.

No hay un despliegue on-premise certificado en este checkout. El gate y los
entregables necesarios están en [`../docs/DEPLOY_LOCAL.md`](../docs/DEPLOY_LOCAL.md).
