Qué es GovTech Platformí

Introducción al sistema de gestión municipal

• Usuario

GovTech Platform es un sistema de gestión integral para municipios, gobiernos y organizaciones públicas o privadas de escala similar. Fue desarrollado inicialmente para la Municipalidad de Junín, Mendoza, y diseado desde el primer día como una plataforma multi-tenant SaaS vendible a cualquier gobierno del mundo.

El sistema permite controlar en tiempo real: gastos, contratos, proveedores, personal, reclamos vecinales, obras públicas, presupuesto anual y mucho más. Incluye un Asistente IA que responde preguntas en lenguaje natural, un WhatsApp Bot para alertas automíticas, y exportación profesional a PDF y Excel.

• Un municipio no es más que una empresa pública con miles de Áreas. Esta plataforma es igualmente aplicable a empresas privadas, cmaras de comercio, bolsas, universidades, hospitales, consorcios y cualquier organización con necesidad de control financiero y gestión de personal.

Predictor IA

El predictor calcula automíticamente el gasto proyectado al cierre del año usando regresión lineal ponderada sobre los Últimos 7 meses. Genera alertas cuando detecta partidas en riesgo de superar el presupuesto.

Arquitectura Multi-Tenant

Cómo escalar a míltiples municipios

• Túcnico

El sistema está diseado como SaaS multi-tenant desde el primer día. Cada municipio (tenant) comparte la misma codebase pero tiene datos completamente aislados en la base de datos.

Aislamiento de datos
Prisma Cada query filtra por tenantId automíticamente
// El middleware extrae tenantId del JWT

const contratos = await prisma.contrato.findMany({

  where: { tenantId: req.user.tenantId }  // • Siempre aislado

});
