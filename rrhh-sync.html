🔌 Opción 1 — Conexión Directa a Base de Datos

Ingresá las credenciales de la base MariaDB/MySQL del municipio. MuniControl se conectará directamente para importar y actualizar los datos automáticamente.

🔒 Las credenciales se almacenan encriptadas en el servidor.
📤 Opción 2 — Carga Manual de Archivos

Subí un archivo CSV o JSON con los datos actualizados. Ideal para actualizaciones puntuales o cuando no hay conexión directa disponible.

📂
Arrastrá un archivo aquí o hacé click para seleccionar
Formatos aceptados: .csv, .json · Máximo 50MB
